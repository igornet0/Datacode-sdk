# Примеры SDK

## hello_module (Rust)

Расположение: `examples/hello_module/`.

Минимальный нативный модуль с одной экспортируемой функцией `hello()`: выводит сообщение и возвращает null.

- **Сборка:** из `datacode_sdk/examples/hello_module` выполните `cargo build --release --lib`, либо из `datacode_sdk/tools` запустите `./build_abi.sh ../examples/hello_module`.
- **Результат:** `libhello_module.dylib` (или `.so`). Скопируйте в каталог, откуда запускаете скрипты DataCode, или запускайте скрипты из этого каталога.
- **Использование** (DataCode):

  ```dc
  import hello_module
  hello()
  ```

## hello_world.dc

Импортирует `hello_module` и вызывает `hello()`. Нужен `libhello_module.dylib` в том же каталоге (или в текущем каталоге) при запуске:

```bash
datacode hello_world.dc
```

## math_module.dc

Заготовка под гипотетический нативный модуль «math» с экспортами `add`, `mul` и т.д. Раскомментируйте и адаптируйте, когда такой модуль появится.

## telegram_bot.dc

Заготовка под бота Telegram через нативный модуль. Реальная интеграция может жить в `datacode_lib/gram_api` или в отдельном ABI-модуле; файл задаёт ожидаемый сценарий использования.

## Ручные обёртки

Если нужен `.dc`-файл, который реэкспортирует или оборачивает нативные функции (например, для документации), его можно написать вручную. В будущем инструмент `gen_bindings` мог бы генерировать такие файлы по списку имён или по аннотациям Rust.
